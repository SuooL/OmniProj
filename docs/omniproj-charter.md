# OmniProj 是什么

> 一本能自己对上 git 的笔记本。

## 1. 它替代的东西

一本纸质笔记本。一页写一个项目：项目名，下面 1、2、3 编号的步骤，做完打勾，某一步展开成几条子步骤。

纸笔的问题只有两个：翻起来慢，而且它不知道你在 git 里实际做了什么。OmniProj 只解决这两个，其余照抄。

## 2. 一个项目页长什么样

```
前列腺癌穿刺优化 MRI 预测 <FM>          dev · 12 commits · 3 天前
▁▃▅▂▁▁▇▅▃▁▂▆▅▃▁▁  ← 一年的提交热图
────────────────────────────────────────
 1 ✓ 方案拟定
 2 ✓ Down Stream Task 定义
 3 ✓ 报告提取
     ✓ OCR
     ✓ 结构化批量
 4 ✓ CT 数据 DICOM 批处理转换管线
 5 □ 论文框架搭建                    09-20
 + 新增一步…
```

一页 = 一个项目 = 一份带层级的清单，加上这个仓库的 git 活动。没有第二个视图。

## 3. 交互

清单就是编辑器，不需要先点「编辑」：

| 操作 | 结果 |
|---|---|
| 点方框 | 打勾 / 取消打勾 |
| 点文字 | 就地改写 |
| 回车 | 在下面新起一行 |
| Tab / Shift+Tab | 缩进成子步骤 / 退回上一层 |
| ⌥↑ ⌥↓ | 上下调整顺序 |

子步骤跟着父步骤走：缩进、拖动、删除，整棵子树一起动。

## 4. git 那一半

git 侧的信息**全部自动派生**，一条都不用手录：

- **提交热图** —— 一年的每日提交数，一眼看出哪段时间在动、哪段停了。
- **提交时间线 / 分支图** —— 只读，收在折叠区里。
- **task ↔ commit 关联** —— 一个步骤可以挂多个 commit，多对一。

**对你的仓库零写入。** OmniProj 只跑只读的 git 命令，自己的状态写在 `~/.omniproj`（可用 `OMNIPROJ_HOME` 改）。删掉那个目录，你的仓库毫无痕迹。

## 5. AI 的位置

**只有一处**：某一步想不清怎么拆，点「让 AI 拆成子步骤」，它给候选，你勾选采纳，采纳的条目落成这一步的子步骤。

AI 不自动执行任何东西，不改代码，不提交，不替你决定。没勾选就什么都不会写进你的清单。远程 provider 只发送这一步的文字和备注，且需要你显式同意；API key 存在系统钥匙串，不落盘到 `~/.omniproj`。

## 6. 不做

- **不做自主执行的 agent。** 建议可以，代劳不行。
- **不做通用笔记 / PKM。** 这里只有「项目 → 步骤」。
- **不做通用 git 客户端。** gitk / lazygit / GitHub 已经够好；这里的 git 视图只服务于「这个项目最近在动吗、这一步对应哪些提交」。
- **不做优先级排序、健康分、腐坏度评分。** 工具报告事实，不替你判断哪个项目更要紧。列表按你选的方式排，仅此而已。
- **不做多人协作、云同步。** 单用户，本地优先。

## 7. 数据

全部是本地文件，人类可读：

```
~/.omniproj/
  meta.toml                        # 项目登记表
  projects/<ProjectId>/
    meta.toml                      # 这个项目的登记信息 + 仓库位置
    notes/project.md               # 步骤清单（TOML front matter + 你的正文）
    cache/r0-observation.json      # 最近一次仓库观测（派生的，可重建）
```

`~/.omniproj` 本身是一个 git 仓库，每次写入是一次可回退的提交。复制目录即迁移。

## 8. 历史

2026-09 之前，这个项目围绕一套「重入成本 / 当前承诺 / planned-vs-actual 对账 / 腐坏度」的词汇建了四轮。那套词汇解释起来比用起来复杂，任务还是扁平的一层，笔记本上最基本的「第 3 步展开成三条」都表达不了。R4 把它换成了上面这一页。

被移除的概念（不再有对应的界面或 IPC 命令）：Current Commitment 及其 confirm / complete / switch-away / undo 生命周期、重入上下文、独立的决策记录、待审视 / 静默 / 需要你决定 的分组与徽章、dogfood 重入计时。

底层 `notes/project.md` 里仍保留承诺变更日志字段，因为已有的本地数据带着它，删掉会读不开旧文件。它不再出现在任何界面上。
